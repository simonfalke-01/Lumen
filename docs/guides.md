## Protocol references

- [Client microphone v1](protocols/umbra-microphone-v1.md): production
  authenticated client-to-host microphone extension.
- [Umbra/Lumen QUIC v3](protocols/umbra-lumen-quic-v3.md): experimental
  single-port design and prototype, not shipped.
- [Windows VDD source status](../src/platform/windows/virtual_display_driver/README.md)
  - source and validation bundle, not a packaged driver.

The protocol documents distinguish normative wire rules from implementation
status. Portable tests do not prove Windows driver, GPU, display, network, or
input-to-photon behavior.
